เลือกเมนูเพื่ออ่านผล CI

CI PASS ไม่เท่ากับตรวจ QA อิสระ ตัวตน QA ผ่าน GitHub Bridge ยังเป็นบทบาทที่ผู้ส่งคำสั่งอ้างเท่านั้น

เลือกโปรเจกต์

Repository ที่อนุญาตให้ทำงานและดูผล

ขั้นตอนสั้นที่สุด

  1. เปิด GitHub Connector ในแชท CEO และให้สิทธิ์ Repository ai-organization-hub
  2. สั่งให้ AI สร้างไฟล์ที่ bridge/requests/YYYY-MM-DD/UUID.json บน main ด้วย action open_room
  3. Worker อ่านคิวอัตโนมัติทุก 5 นาที หรือกดรับคำสั่งตอนนี้บนเว็บไซต์
  4. AI ดู Receipt และ Inbox ผ่าน URL API แบบอ่านอย่างเดียว แล้วส่งคำสั่ง appoint / task / message / task_status เป็นไฟล์ใหม่
  5. งานแก้โค้ดและ PR ใช้ GitHub Connector ตรง ไม่ใช่ตัวแก้ไขผ่านเว็บ
